## 🚀 Getting Started

### Prerequisites

- **Ruby** (with Bundler) for Jekyll development
- **Docker** (optional) for containerized development

### Local Development

1. **Clone the repository:**
   ```bash
   git clone https://github.com/MdRifat-Hossen/mdrifat-hossen.github.io.git
   cd mdrifat-hossen.github.io
   ```

2. **Install dependencies:**
   ```bash
   bundle install
   ```

3. **Run the development server:**
   ```bash
   bundle exec jekyll serve --livereload
   ```

4. **Visit the site:**
   Open your browser and go to `http://localhost:4000`

### Docker Setup (Optional)

```bash
docker-compose up
```

Then visit `http://localhost:4000`

## 📝 Content Management

### Adding Publications
- Add new publication entries to `_publications/` directory
- Follow the existing YAML front matter format

### Adding Blog Posts
- Create new markdown files in `_posts/` with the format: `YYYY-MM-DD-title.md`
- Include proper front matter with layout, title, and categories

### Adding Projects
- Add project entries to `_portfolio/` directory
- Include images and descriptions

### Adding Teaching Materials
- Add teaching content to `_teaching/` directory

### Adding Talks & Presentations
- Add talk entries to `_talks/` directory
- Use the talkmap.py script for location visualization

## 🔧 Customization

Edit `_config.yml` to customize:
- Site title and description
- Author information and social profiles
